## Getting Started 

### Prerequisites

- [Node.js](https://nodejs.org/) 20 or later
- npm (comes with Node.js)

### Installation

```bash
git clone https://github.com/<your-username>/nexascan-web.git
cd nexascan-web
npm install
```

### Running locally

```bash
npm run dev
```

Then open http://localhost:3000 in your browser.

### Building for production

```bash
npm run build
```
